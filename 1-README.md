## 🇪🇸 Español

Documento de **diseño de casos de prueba** de una app web multi-tenant (mi producto **Advoga+**, un generador de posts para abogados): generado con IA y **revisado caso a caso contra el código real**.

Muestra el proceso completo de QA:

- ✅ El prompt usado para generar los casos
- ✅ 24 casos de prueba: registro, login, posts, invitaciones, rutas protegidas, aislamiento entre clientes y móvil
- ✅ Qué corregí de la salida de la IA y por qué
- ✅ Qué aprendí del proceso

Los flujos principales están automatizados con **Playwright** (46 tests, en CI con GitHub Actions a cada cambio).
